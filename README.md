# మన తెలుగు · Mana Telugu

Live site: **https://sda2025-tech.github.io/mana-telugu/**

A Pedda Balasiksha-style primer for learning Telugu: **అచ్చులు**, **హల్లులు**, **గుణింతాలు**, **ఒత్తులు**, words, sentences, numbers, rhymes, and a short practice quiz.

Tap any letter to hear it (Telugu speech works best in Chrome or Edge when a `te-IN` voice is available).

## Local preview

```bash
python3 -m http.server 8080
```

Then open `http://localhost:8080`.

## Lessons

1. Achulu — 16 vowels with picture words
2. Hallulu — 36 consonants by varga
3. Guninthalu — vowel signs on each consonant
4. Vattulu — conjuncts
5. Padalu / Vakyalu / Sankhyalu / Geyalu
6. Abhyasam — practice
